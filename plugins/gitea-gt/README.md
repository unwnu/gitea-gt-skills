# Gitea gt

This plugin gives Claude Code and Codex one skill for the official Gitea `gt` CLI. It covers repositories, issues, pull requests, releases, Actions, and related resources. Install `gt` and connect to Gitea 28 or newer before using the skill. The skill reads installed command help. It includes no server, token, or script.

In Claude Code, run `/plugin install gitea-gt --marketplace unwnu/gitea-gt-skills`. See the [marketplace README](https://github.com/unwnu/gitea-gt-skills) for Codex instructions.
